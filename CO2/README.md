# CO2 Mobile Telecommunication Systems Simulator

## Files
- `co2_app.html` — application page
- `co2_style.css` — styling
- `co2_simulator.js` — interactive simulation logic

## Run
Open `co2_app.html` in a modern browser. No installation or server is required.

## Included experiments
- Q1: device classification and immediate-send vs store-and-forward
- Q2: FDMA/TDMA usable capacity and traffic occupancy
- Q3: simplified DS-CDMA spreading, code correlation and near-far illustration
- Q4: OFDMA contiguous, round-robin and channel-aware allocation over seeded fading trials
- Q5: ideal ULA response and angular separation illustration
- Q6: weighted multiple-access decision matrix
- Q7: dedicated resource reservation vs dynamic pooled allocation

## Important modelling note
This is an educational prototype, not a standards-compliant GSM or radio-network simulator. It uses simplified assumptions and illustrative scoring. State assumptions, validate calculations, add cited standards parameters, and compare outputs with your own analysis before using results in the assignment report. Q3 and Q5 in particular are simplified models and should be extended/checked before treating their outputs as engineering measurements.
