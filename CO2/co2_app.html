QUESTION 07 · DAY 4

Diagnose, redesign and validate

13 marks

Example redesign: dedicated channels can remain idle when traffic is bursty. Compare a fixed dedicated allocation with a pooled on-demand allocation under the same offered traffic.

Run the comparison to measure idle and blocked resources.

Redesign logic

  1. Diagnose: a dedicated channel is reserved even when its user is inactive.
  2. Objective: reduce idle channel-time while keeping blocking low.
  3. Revised strategy: allocate a channel only when a user has data to send; release it after transmission.
  4. Trade-off: the pooled system needs scheduling and control signalling.
