Three distinct frequency-planning strategies

Compare how each strategy shares the same 336 duplex channels.

STRATEGY A

Fixed cluster reuse

Partition channels into N groups. Repeat the same group only after the reuse distance D = R√(3N).

Principle: spatial reuse

Access: FDMA/TDMA channel groups; separate control channels.

for each valid (i,j):
N = i² + ij + j²
Q = √(3N)
assign group[c] = c mod N
check SIR ≥ threshold
STRATEGY B

Sectorised reuse

Split each site into 3 or 6 directional sectors. Antenna patterns reduce the dominant co-channel interferers.

Principle: spatial filtering

Access: FDMA/TDMA or OFDMA resources per sector.

for each site:
create S directional sectors
assign sector channel plan
evaluate front/back leakage
retain plan if SIR ≥ target
STRATEGY C

Hierarchical + borrowing

Keep macro coverage, add microcells in hotspots and borrow idle channels from neighbours subject to interference checks.

Principle: trunking + spatial reuse

Access: dynamic channel assignment; control plane anchored to macro layer.

split(cell, demand):
if demand ≤ capacity: return
deploy micro layer
divide radius by 2
recurse on overloaded child cells
borrow idle channels if SIR-safe

Decision

MODIFY temporarily — do not permanently redesign the township.
Deploy event-time cells-on-wheels / temporary microcells, sectorise the stadium, enable coordinated dynamic channel borrowing and apply admission control. Keep the macro layer for continuity and mobility.
  • Four-hour predictable surge makes temporary capacity more economical than permanent sites.
  • Use low-power stadium cells to contain interference and reduce spillover.
  • Plan backhaul, power, synchronisation and handover zones before event day.
  • Twice-monthly frequency justifies a reusable temporary deployment kit.
Important spectrum constraint: temporary cells do not create new licensed spectrum. Their capacity comes from spatial reuse, sectorisation, tighter interference coordination and borrowing idle resources. If the same channels cannot be reused at the required SIR, the offered load must be reduced through Wi-Fi offload, admission control or operator-supported spectrum sharing.
