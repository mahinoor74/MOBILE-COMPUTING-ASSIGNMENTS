Technical comparison

ParameterCellular networkAd hoc network
InfrastructureFixed base stations and coreNo fixed infrastructure required
CommunicationUsually through base stationDirect or multi-hop between nodes
RoutingManaged by network infrastructureDistributed routing among nodes
TopologyPlanned cell structureDynamic topology
HandoffSupported by cellular mobility proceduresRoutes/links may need rediscovery
Failure handlingMay depend on surviving infrastructureCan reroute if alternate node paths exist
ApplicationsPublic mobile broadband, voiceDisaster response, temporary teams
Engineering decision: In a disaster area with unavailable fixed infrastructure, a MANET can provide local multi-hop communication. A hybrid design can reconnect to cellular or satellite backhaul when available.

Higher, fresh sequence numbers help identify newer routes and avoid stale routing information.

DSDV behaviour

Periodic route updates→Sequence number comparison→Routing table refresh→Route ready when needed

Advantage: routes are available before data transmission. Limitation: periodic updates can create control overhead, especially when the topology changes frequently.
