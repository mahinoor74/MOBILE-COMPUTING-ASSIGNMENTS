# CO3 – Wireless Mobility & Routing Lab

An interactive educational website for Mobile Computing Assignment 3 (CO3).

## Files
- `co3_app.html` – main website
- `co3_style.css` – responsive interface styling
- `co3_simulator.js` – interactive simulations and calculations

## Run locally
1. Keep all three files in the same folder.
2. Open `co3_app.html` in Chrome, Edge, or Firefox.
3. Select Q1–Q7 from the navigation menu and run the interactive controls.

No server or package installation is required.

## Included modules
1. Wireless network architecture and mobility scenario
2. Mobile IP architecture, registration and packet flow
3. Cellular versus ad hoc network comparison
4. Mobile IP application example and performance estimate
5. DSDV routing table/topology illustration
6. AODV versus DSDV comparison
7. Emergency communication network design and simplified evaluation

## Important modelling note
The numerical outputs are simplified illustrative models intended for learning and scenario comparison. They are not results from ns-3, OMNeT++, a real radio network, or standards-conformance testing. State assumptions clearly in any report and do not present illustrative outputs as measured experimental data.

## Assignment collaboration
The assignment requires both partners to understand and contribute to all questions. Use this website as an interactive aid and prepare the required individual analysis, shared design, diagrams, evidence and viva explanations separately.
